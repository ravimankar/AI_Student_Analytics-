# 🎓 AI Student Performance & Career Analytics

AI Student Performance & Career Analytics is a Python-based student analytics application that helps analyze student performance, attendance, skills, and career-related insights through an interactive Streamlit dashboard.

## ✨ Features

* 📊 Student performance analysis
* 📈 Marks and attendance analytics
* 🎯 Performance category analysis
* 🧠 Student skills analysis
* 💼 Career-role insights based on skills
* 🤖 AI Assistant for student-related queries
* 📁 CSV-based student data management
* 🗄️ SQLite database support
* 📉 Data visualization using charts
* 🌐 Interactive web dashboard using Streamlit

## 🛠️ Technologies Used

* Python
* Streamlit
* Pandas
* Matplotlib
* SQLite
* Ollama
* Git & GitHub

## 📊 Analytics

The application can analyze:

* Student-wise performance
* Subject-wise average marks
* Attendance
* Performance categories
* Skill matching
* Career-related insights

## 🤖 AI Assistant

The project includes an AI Assistant that can interact with the student analytics application and provide useful responses related to student performance, skills, and career-oriented information.

## 💼 Career & Skills Analysis

The application compares a student's available skills with required skills for a data-related career path and calculates a skill-match percentage.

Example skills include:

* Python
* SQL
* Excel
* Power BI
* Statistics

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/ravimankar/AI_Student_Analytics-.git
```

### 2. Open the project folder

```bash
cd AI_Student_Analytics-
```

### 3. Install required libraries

```bash
pip install streamlit pandas matplotlib
```

### 4. Run the Streamlit dashboard

```bash
python -m streamlit run dashboard.py
```

The application will open in your web browser.
